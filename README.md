# Creator Hub

Next Developer's site — AI assistants, digital products, and creator resources.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Local development

```sh
# Install dependencies
npm i

# Start the dev server
npm run dev
```

## Deployment

Deployed on Vercel — pushes to `main` deploy automatically.
